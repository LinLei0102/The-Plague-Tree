# 病毒树（The Plague Tree）

一款基于 **The Modding Tree** 引擎的增量游戏，主题是病毒与疫情。本仓库为其**简体中文汉化版**。

- **游戏名**：Plague Tree（Vorona Cirus Treesease）
- **作者**：Vorona
- **版本**：v0.6.25
- **汉化**：简体中文汉化层（详见 [`localization/README.md`](localization/README.md)）

> 汉化说明：本仓库在 `localization/` 目录内置了「词典 + 运行时翻译引擎」的独立汉化层，
> 不改动 `js/` 下任何游戏源码。删除 `index.html` 末尾引入汉化层的两行 `<script>` 即可回到英文原版。
